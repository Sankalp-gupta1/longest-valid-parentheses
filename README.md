
# Longest Valid Parentheses

Python solution for finding the length of the longest valid parentheses substring.

## Approach
Uses a stack to track the indices of unmatched parentheses.

## Complexity
- Time Complexity: O(n)
- Space Complexity: O(n)

## Examples
- Input: "(()"       Output: 2
- Input: ")()())"    Output: 4
- Input: ""          Output: 0

## Language
Python 3
